MHServerEmu 0.8.1 Has Been Released

Mar 6, 2026

The stable release of MHServerEmu 0.8.1 is now available on GitHub!

0.8.1 Features

You can find the full list of changes for 0.8.1 in the release notes on GitHub, but to summarize:

  • Big optimization pass.

  • Achievement system polish.

  • Autosaving.

  • Ultimate Prestige (not to be confused with Omega Prestige).

  • Backend changes to prepare the server for 1.48 support.

  • Minor features (e.g. party leave grace period, map discovery data synchronization, etc.).

  • Bug fixes.

0.8.1 is the final stable version before the long-awaited 1.0.0 milestone. As such, this is also the final planned version that will support player data from the 0.x branch. Your older data will not be “wiped” per se, but if you update to 1.0.0 or a later stable release, the server will ignore 0.x data and enforce a fresh start. If you would like to keep your local progress, we recommend to continue play using version 0.8.1.

1.0.0 Release Date

I am excited (and a little bit nervous) to announce that after over 2.5 years of development the MHServerEmu project will be officially exiting its “beta” stage of development on March 20, 2026 with the release of stable version 1.0.0. While we work on making last minute adjustments over the next two weeks, please be sure to participate in any stress tests hosted by community servers that get announced. We will do our best to try and make it as little of a disaster on community servers as possible!

Thank you all for following the development of MHServerEmu over the past few years. We hope to see you all playing on March 20!
