MHServerEmu

You can download the latest stable release of MHServerEmu on GitHub. Stable releases do not have all the latest features, but they are easier to set up and are less likely to contain game-breaking issues. For most normal gameplay it is recommended to use stable releases.

The latest nightly build of MHServerEmu is available via nightly.link. Nightly builds use current work-in-progress code and may contain issues.

The setup instructions can be found in our documentation. If you are having issues setting everything up, feel free to ask for help on our Discord server in the #setup-help channel.

The source code is licensed under AGPLv3 and is available on GitHub.

MHServerEmu requires original game data files to function. You will have to legally acquire and provide them yourself to use the emulator. If you have ever played the game on Steam, you should still be able to download the game in your Steam library.

MHServerEmu2013

MHServerEmu2013 is an experimental version of MHServerEmu that can be used with game version 1.10 from mid 2013. It is still very very early in development and should not be used unless you share my unhealthy obsession with old versions of Marvel Heroes.

Tools

Over the course of development of MHServerEmu we also made a number of tools that you may find useful.

Bifrost

Bifrost is a custom launcher for Marvel Heroes that allows you to manage connection settings for different servers and configure various hidden client options.

OpenCalligraphy

OpenCalligraphy is a data browser for the Calligraphy framework, which is used to handle all static data in Marvel Heroes.

MHServerEmu.Gui

MHServerEmu.Gui is a graphical user interface (GUI) implementation for MHServerEmu that uses the Avalonia framework. It is designed primarily with handheld PCs like Steam Deck in mind, but can be used on desktops as well.
